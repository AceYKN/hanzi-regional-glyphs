## 实用性与视觉调整

- 取消大段宣传首屏与重复 HOW IT WORKS/WHY DIFFERENT 内容，查询结果更靠前。
- 保留搜索、逐字查看、读音、对应字、Unicode、笔画、字号、主题、分享、放大和叠加。
- 四套独立地区字体各一张卡片；新加坡、马来西亚共用配置用一行说明保留。
- 手机采用两列结果卡片，四个地区均可顺序看到；取消隐藏滚动条的横向地区轮播。
- 将完整方法、来源、版本、限制及许可集中于“资料与说明”，结果页只保留与当前操作相关的提示。
- 普通界面使用系统字体，地区字体只用于字形，以减少正文的字体下载与混淆。

## 准确性边界

“同字字形”比较固定 Noto CJK 字体的字形，不代表全部地区字体、手写习惯或法定字形标准。OpenCC 是转换参考，不是词义判定或规范认证。Unihan 是可追溯的基础资料，字段可能缺失或多值；读音不等同于词中发音，笔画数可能存在地区差异。支持汉字输入不表示每个字体都收录该字。

所有数据与字体均固定版本、保留来源及许可；字体实际不支持的字不会回退到系统字体后继续标注为地区字体。未缓存字体分片的离线加载失败会提示联网重试。

## 后续值得做的增强

1. 将有争议的读音、异体或地区对应建立可引用的勘误清单，要求提交具体来源。新增人工覆盖数据时记录出处、版本、审阅理由，避免重新引入无来源硬编码。
2. 若扩展至词语语境转换，保留原文、词义候选及转换依据，不把单字转换直接包装成准确文本翻译。
3. 若需要代表官方字形规范，应另行引入相应地区权威规范及可核查图样，界面明确区分官方资料与字体实例。
4. 增加 Firefox/Safari 和实体手机回归、安装 PWA 图标及可用性测试。本次自动浏览器证据限于 Chromium，不等同于这些环境已验收。
5. 每次数据或字体版本更新重复完整浏览器流程、离线重启、旧版本升级及视觉检查。当前 CI 提供静态/单元验证，浏览器脚本保留可重复执行入口。

验证结果和可重复命令见 `verification.md`。
